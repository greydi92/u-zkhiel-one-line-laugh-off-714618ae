# One-Line Laugh-Off — "I tried to start a cult, but everyone kept asking for the refund policy."

Built for the [make.fun "One-Line Laugh-Off" bounty](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) — a program that writes exactly one funny line to `/output/entry.txt`. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

The line: a would-be cult leader meets the modern consumer — his followers treat the cult like a bad product and demand the refund policy. No setup, no explanation, 72 characters.

## Run

```sh
node main.ts
```

Node 22, no network, no dependencies. Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
